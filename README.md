# Работа под учёбу

MVP для IT Challenge №2 «Product Battle».

Студент отмечает, когда он свободен от пар, что умеет и какая работа интересует. Сервис показывает подработки без опыта с rabota.by, praca.by и gsz.gov.by, которые можно совмещать с учёбой, и собирает резюме.

- `index.html` — страница сервиса.
- `vacancies-extra.js` — 746 вакансий без опыта с rabota.by (219), praca.by (228) и gsz.gov.by (299, временная работа для студентов), собраны 14–16.11.2026; ещё 18 внутри `index.html`, всего 764.
- `internships.js` — стажировки и практика: проверка «подхожу ли я», письмо-заявка, трекер заявок, напоминания в календарь.
- `profiles.js` — «Мои анкеты»: сохранить, выбрать готовую, создать новую, удалить; скачать анкету в файл и загрузить на другом устройстве.

Вакансии со временем закрываются: перед откликом проверяйте ссылку.
