# Работа под учёбу

MVP для IT Challenge №2 «Product Battle».

Студент отмечает, когда он свободен от пар, и что умеет. Сервис показывает вакансии без опыта с rabota.by, которые можно совмещать с учёбой, и собирает резюме.

- `index.html` — страница сервиса.
- `vacancies-extra.js` — 219 вакансий, собранных с rabota.by 15.11.2026 (ещё 18 внутри `index.html`, всего 237).

Вакансии со временем закрываются: перед откликом проверяйте ссылку.
